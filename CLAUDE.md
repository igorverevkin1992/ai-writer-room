# CLAUDE.md — Writers Room OS

Персональный local-first инструмент разработки сериалов для одного шоураннера.
Не универсальный конструктор методологий: приложение **жёстко имплементирует одну
рабочую систему** и не должно обрастать альтернативными фреймворками структуры.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Vite на http://localhost:5173 (host: true — доступен извне контейнера) |
| `npm run build` | `tsc --noEmit` + продакшн-сборка в `dist/` |
| `npm run typecheck` | Только проверка типов |
| `npm run test` | Vitest, один прогон |
| `npm run test:watch` | Vitest в watch-режиме |
| `npm run lint` | ESLint по `src/**/*.{ts,tsx}` |

Перед коммитом: `npm run typecheck && npm run lint && npm run test`.

## Методологическое ядро

Пять слоёв занимают непересекающиеся места в коде. Не смешивать.

| Слой | Источник | Где живёт |
|---|---|---|
| 1. Жанр — ЧТО обязано случиться | Труби | `GenreBeat`, сид-библиотека `src/db/seed/genreBeats.ts` |
| 2. Структура — ГДЕ это случается | Хармон | `StructureNode.circle` (8 слотов) |
| 3. Персонаж — КТО меняется | Уайлэнд | `Character` + `CharacterArcState` |
| 4. Тактика — КАК устроен поворот | Моури | `StructureNode.whatIsGained/costPaid`, `Scene` |
| 5. Текст — КАК написано | Финчер | стилевой промпт `FINCHER_PROFILE` в `src/ai/prompts.ts` |

Центральная фича продукта — **назначение жанровых битов на узлы структуры**
(`GenreBeat.assignedNodeId`, many-to-one) и честный счётчик покрытия. Биты Труби и
шаги круга Хармона — разные оси: бит это требование к содержанию, шаг — структурный слот.

Слой 5 правится **только** в промпте режима 6, а не в модели данных.

## Схема сущностей

```
Project 1—1 StoryBible
Project 1—N GenreBeat        → N—1 StructureNode (assignedNodeId, nullable)
Project 1—N StructureNode    (дерево через parentId: work → season → episode → act)
Project 1—N Character        → N—N StructureNode через CharacterArcState
StructureNode 1—N Scene
Project 1—N AIConversation
```

Определения — `src/types.ts` (единственный источник правды по формам данных),
индексы Dexie — `src/db/db.ts`, вся запись — через `src/db/repo.ts`.

Ключевые инварианты:
- `StructureNode.circle` — всегда ровно 8 слотов по шагам 1..8. Любые данные снаружи
  прогоняются через `normalizeCircle()`.
- `StructureNode.circleStep` — не круг узла, а его позиция в круге родителя.
- `GenreBeat.status` производен: `unplaced` без узла, `placed` с узлом, `twisted` —
  флаг трансценденции, живущий поверх размещения. Ставить статус руками нельзя,
  только через `assignBeat()` / `setBeatTwist()`.
- Удаление узла снимает назначения битов, но не удаляет сами биты.

## Проверки методологии

`src/lib/validate.ts` — только то, что проверяемо формально; всё оценочное отдаётся AI.

- покрытие битов (`coverage`);
- пустые шаги круга, FIND==TAKE, TAKE без FIND (`circleDefects`);
- незаполненная цена на уровне акта, пинч-поинт без давления оппозиции (`nodeDefects`);
- стыковка CHANGE→YOU между сиблингами (`continuityLinks`) — эвристика Жаккара по
  значимым словам, порог `CONTINUITY_THRESHOLD`; автор может подтвердить стыковку
  вручную (`StructureNode.continuityAck`);
- откаты состояния Лжи и отсутствие Момента истины на мидпоинте (`arcDefects`);
- мёртвая сцена: нет задачи/препятствия/поворота/сдвига заряда (`sceneDefects`).

Порог совпадения — эвристика, а не истина: при изменении формулировок правьте
константы в одном месте и обновляйте тесты.

## AI

`src/ai/` — клиент, промпты, сборка контекста. Шесть режимов, см. `AIMode`.

Порядок промпта задан ради кэширования и менять его нельзя:

```
system[0] = Блок A: роль + ядро проекта + мир + библия персонажей   ← cache_control: ephemeral
system[1] = Блок B: системная рамка режима
messages  = динамический контекст (узел / сцена / матрица) + запрос автора
```

Блок A обязан быть побайтово стабильным между запросами — никаких дат, счётчиков и
случайных id. Минимальный кэшируемый префикс — 1024 токена, панель предупреждает,
если библия короче. Проверка живого кэша: `cache_read_input_tokens > 0` во втором
запросе (виден в счётчике панели AI).

Модели и цены — `src/ai/models.ts`. ID моделей и ставки меняются, перед долгими
прогонами сверять с platform.claude.com. По умолчанию `claude-opus-5`.

Вызов идёт прямо из браузера: `dangerouslyAllowBrowser: true` (SDK сам ставит
`anthropic-dangerous-direct-browser-access: true`), ключ BYOK в localStorage.
Ретраи 429/5xx — внутри SDK (`maxRetries: 4`), человеческие сообщения об ошибках —
в `toAIError()`.

## Конвенции кода

- React 19 + TS strict + Tailwind. Функциональные компоненты, без классов.
- Запись в базу — только через `src/db/repo.ts`; экраны не трогают Dexie напрямую,
  кроме мелких правок библии в `Overview`.
- Чтение — через `useLiveQuery` (`src/lib/hooks.ts`); UI перерисовывается сам.
- Поля ввода коммитят значение по blur (`TextInput` / `TextArea` из `components/ui.tsx`),
  не на каждый keystroke — иначе IndexedDB получает шторм записей.
- Весь UI и все промпты — по-русски. Идентификаторы и типы — по-английски.
- Никаких `any`; ESLint это ловит.

## Чего не делать

- Не добавлять альтернативные модели структуры (Save the Cat, Field и т. п.).
- Не хардкодить жанровые биты в UI: библиотека копируется в проект и редактируется
  автором, формулировки из публичного резюме требуют сверки с первоисточником.
- Не превращать `targetPercent` в константу: для 8 серий и вертикали проценты
  Уайлэнд пересчитываются.
- Не отправлять данные проекта никуда, кроме api.anthropic.com.
