# Writers Room OS

Персональный local-first инструмент разработки сериалов. Одна методологическая
система, зашитая в модель данных, и AI-ассистент поверх неё.

**Труби** (жанр) → **Хармон** (структура) → **Уайлэнд** (персонаж) → **Моури** (тактика) → **Финчер** (текст)

| Слой | Отвечает на вопрос | Как реализован |
|---|---|---|
| Жанр | ЧТО обязано случиться | Редактируемая библиотека обязательных битов, назначаемых на узлы структуры |
| Структура | ГДЕ это случается | Круг Хармона на трёх уровнях: произведение → сезон → серия → акт |
| Персонаж | КТО меняется и как | Ложь / Призрак / Хочет / Нужно + состояние Лжи по каждому биту |
| Тактика | КАК устроен поворот | «Что получает / какую цену платит» на каждом узле, карточка сцены |
| Текст | КАК написано на странице | Стилевой профиль в промпте, а не поле данных |

Инструмент не пишет за автора. Он показывает, какие обязательные биты жанра ещё не
размещены, в каком состоянии Ложь каждого персонажа на каждом структурном бите и
почему конкретная сцена не работает.

## Что умеет

- **Покрытие жанра.** Ведущий жанр + 2–3 поддерживающих, библиотека битов подтягивается
  автоматически и редактируется. Биты перетаскиваются на узлы структуры, счётчик
  показывает честное «размещено N из M», неразмещённые подсвечены.
- **Трансценденция бита.** Флаг «вывернут» с заметкой (перестановка / инверсия /
  замена носителя) и AI-режим, предлагающий три способа вывернуть конкретный бит.
- **Круг Хармона на трёх уровнях** с автоматической проверкой: пустые шаги, FIND и TAKE
  как одно событие, разрыв стыковки CHANGE → YOU между соседними узлами.
- **Персонажи по Уайлэнд + Моури:** убеждения, Ложь, Призрак, Хочет, Нужно, шесть типов
  арки, ставки внешние и философские, позиция на философском спектре, профиль голоса,
  паутина связей с конфликтом убеждений.
- **Матрица арок:** персонаж × структурный бит = состояние Лжи, с подсветкой
  подозрительных переходов (откат позитивной арки после мидпоинта, отсутствие Момента истины).
- **Двигатель «хочет и цена»:** на каждом акте два обязательных поля; незаполненная
  цена подсвечивается как дефект структуры.
- **Доктор сцены:** задача сцены, суперзадача, препятствие, тактики, поворот, сдвиг
  заряда, три вопроса Мэмета, позиция зрителя — и кнопка «почему сцена мёртвая».
- **Финчеровский проход:** переписывание текста по стилевому профилю плюс отдельный
  список того, что вырезано и по какому правилу.
- **Шесть режимов AI** с кэшированием статичной библии и видимым счётчиком попаданий в кэш.

## Установка

```bash
npm install
npm run dev            # http://localhost:5173
```

Или в Docker: `docker compose up --build`.

Ключ Claude API вводится в «Настройках» внутри приложения (BYOK). Он хранится в
localStorage браузера и уходит только на api.anthropic.com. На общем компьютере
ключ лучше не сохранять.

## Данные

Local-first: всё лежит в IndexedDB этого браузера, бэкенда нет. **Единственный бэкап —
экспорт проекта в JSON** на экране «Обзор проекта». Очистка данных сайта удаляет
проекты безвозвратно.

## Стек

React 19 · TypeScript · Vite · Tailwind · Dexie (IndexedDB) · dnd-kit ·
Anthropic SDK (прямой вызов из браузера, prompt caching)

## Оговорки

- Списки жанровых битов собраны из публичного резюме «Анатомии жанров» Труби, а не из
  первоисточника. Формулировки и количество битов следует сверить с изданием и
  отредактировать прямо в приложении — библиотека для того и редактируемая.
- Таблица выравнивания слоёв (шаг круга ↔ бит Уайлэнд ↔ тактика) — рабочий синтез, а не
  позиция авторов. Прямо подтверждено источником только «мидпоинт = FIND + TAKE» (Моури).
  Проценты Уайлэнд — ориентиры для романа и полного метра; для 8-серийного детектива и
  50-серийной вертикали их надо пересчитывать, поэтому `targetPercent` — редактируемое поле.
- Пинч-поинты у Моури проработаны слабее мидпоинта; тайминг 37 % / 62 % приходит из
  традиции Уайлэнд/Брукса. В инструменте они реализованы как узлы с обязательным полем
  давления оппозиции — это рабочий компромисс, не цитата.
- Финчеровский профиль выведен из его высказываний о дозировке информации, поведении и
  правоте всех сторон спора. Сам Финчер сценариев не писал — это профиль режиссёрского
  требования к тексту. Если результат окажется слишком сухим, профиль правится в одном
  месте: `FINCHER_PROFILE` в `src/ai/prompts.ts`.
- ID моделей Claude и цены меняются — сверяйтесь с platform.claude.com.

Разработка и конвенции — в [CLAUDE.md](./CLAUDE.md).
